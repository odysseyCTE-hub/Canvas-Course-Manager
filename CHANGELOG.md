# What's new in Canvas Course Manager

Newest version first. When you update, the program shows you the notes for the new version.

## 1.3.1
- First-time setup now installs everything at once, including the modern look, so there's nothing extra to click.
- The one-time setup message now makes clear the helper packages are needed for settings spreadsheets.
- Fixed: the Mac launcher can be double-clicked to open the program.

## 1.2.0
- New: "Create settings spreadsheet…" makes a ready-to-edit spreadsheet from your Canvas course (or a blank template). It only reads Canvas and never replaces an existing file.
- Simpler spreadsheet: course ID is set once on Start Here; unused columns removed; gray cells show what doesn't apply.
- Fixed: Assignment group changes were being ignored.
- Previews now list only settings that are actually different from Canvas.
- Settings spreadsheet redesigned: one tab per task, rows grouped by unit, plain-language choices, and help on every column heading.

## 1.1.0

- **One program, many courses.** Each course folder now keeps its own setup (course ID, spreadsheet, words, emojis, and indents). Switch courses with the arrow next to Course folder on the Course setup tab; the program remembers the folders you've used.
- **Your Canvas login works for every course.** You enter it once, and it stays private next to the program.
- **Nothing to redo.** The first time you open this version, your current setup moves into your course folder automatically.
- **Use any emoji you like.** Type or paste one from your emoji keyboard. Titles no longer end up with two emojis, and items already in Canvas keep their current emoji unless you tick "Update emojis on items already in Canvas."
- **A fresh, modern look,** with an optional Dark mode switch at the bottom of the window.
- **Fits small laptop screens.** Tabs scroll when the window is short, so nothing gets cut off.
- If the modern look isn't installed yet, a "Get the modern look" button sets it up in a few seconds.

## 1.0.0 (November 2026)

The first version shared with colleagues.

- Build Canvas modules from your Unit and Lesson folders: lesson plans, HTML lesson pages, presentations, checkpoint quizzes, activities, exams, and hidden answer keys.
- Update due dates, points, titles, publishing, requirements, and prerequisites from the settings spreadsheet.
- Set up everything in the window: Canvas connection, course folder, folder names, emojis, and indentation.
- Double-click launchers for Windows and Mac.
- New: the program checks for updates when it opens and can update itself. It asks first, saves your old version in the "backups" folder, and never touches your settings or course files.
- Safety rules that are always on: preview first, type APPLY for live changes, nothing in Canvas is ever deleted, answer keys stay hidden from students, and unclear title matches are skipped instead of guessed.
